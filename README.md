# 🧁 Claxon's Cupcakes

Welcome to the official repository for **Claxon's Cupcakes**! This website is an interactive ordering platform and showcase for our handcrafted homemade cupcakes baked fresh in South Webster, Ohio.

---

## ✨ Features

- **Interactive Menu & Order Form:** Customers can select cupcake flavors by the dozen and enter special requests or dietary notes.
- **Direct SMS Ordering:** Orders automatically format and open a pre-filled text message sent straight to the baker's phone.
- **Automatic Pricing:** Instantly calculates order totals based on dozen counts.
- **Payment Flexibility:** Supports Venmo, Cash App, Zelle, and Cash on Pickup.
- **About the Baker:** Highlights the baker's background as an English teacher, high school volleyball coach, and mother of five.
